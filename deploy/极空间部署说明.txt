家庭病历档案管理系统 - 极空间部署步骤（v2）
============================================

【第 1 步】解压并上传整个文件夹
  电脑上解压本 zip → 得到 family-files 文件夹（里面有 backend、frontend、deploy、docs 等）。
  用极空间"文件管理"把【整个 family-files 文件夹】上传到任意位置（如 docker/ 下）。
  注意：不要只上传压缩包或只上传部分文件，backend 和 frontend 文件夹必须完整。

【第 2 步】新建 Compose 项目（关键操作）
  极空间 Docker → Compose/项目 → 新建项目。
  **不要手动粘贴内容**，用【选择文件/导入】功能，选中：
      family-files/docker-compose.yml   （就是刚才上传的文件夹根目录下的那个文件）
  这样极空间会把 family-files 当作项目根，构建时才能找到 backend/frontend 子目录。

【第 3 步】替换 3 个密钥（在导入后的配置文本里查找替换）
    CHANGE_ME_JWT_SECRET        → 任意长随机字符串（不换也能跑，建议换）
    CHANGE_ME_OCR_API_KEY       → 你的 DeepSeek API Key（sk-开头）
    CHANGE_ME_ADMIN_PASSWORD    → 初始管理员密码（记下来，登录用）
  保存并启动。

【第 4 步】等待构建
  首次构建约 5-10 分钟（自动拉取国内加速镜像 → 装依赖 → 编译）。
  两个服务最终都应显示"运行中"。

【第 5 步】访问
  浏览器打开：http://极空间IP:8080
  登录：admin / 你设置的密码

【数据与升级】
  - 数据存在项目目录的 data/db、data/uploads（首次启动自动创建）
  - 升级：新版本 zip 解压覆盖（保留 data 文件夹）→ 重新构建启动，数据自动保留
  - 备份 = 复制 data 文件夹；恢复 = 拷回后重启

【常见问题】
  - 构建报 "backend not found" → 第 2 步没有用文件选择器选根目录的 docker-compose.yml，
    或 backend 文件夹没有上传完整
  - 构建拉镜像超时 → 新版已内置国内加速源（docker.m.daocloud.io）；仍超时可在
    极空间 Docker 设置 → 代理 里配置代理后重试
  - 页面打不开 → 看 backend 容器日志（密钥错误 / OCR key 无效）
  - 8080 被占用 → 把 ports 的 "8080:80" 改成 "其他端口:80"
