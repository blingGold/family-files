家庭病历档案管理系统 - 极空间部署步骤
========================================

【第 1 步】把 zip 解压到极空间存储空间
  用极空间"文件管理"上传本 zip 到任意目录（如 docker/），然后在极空间里解压。
  解压后你会看到一个 family-files 文件夹，里面有 backend、frontend、deploy 等子文件夹。

【第 2 步】打开 Docker Compose / 项目
  极空间 Docker 应用 → 左侧找 "Compose" 或 "项目" → 新建项目。

【第 3 步】粘贴部署配置
  用极空间的"选择文件/导入"功能，选择文件夹里的这个文件：
      deploy/docker-compose.zspace.yml
  （如果没有导入按钮，就把该文件内容复制粘贴进编辑框）

【第 4 步】修改 3 个密钥（重要！）
  在粘贴的配置文本里，找到下面 3 处并替换成你自己的值：
    CHANGE_ME_JWT_SECRET        → 任意长随机字符串（不换也能跑，建议换）
    CHANGE_ME_OCR_API_KEY       → 你的 DeepSeek API Key（sk-开头）
    CHANGE_ME_ADMIN_PASSWORD    → 初始管理员密码（记下来，登录要用）
  保存并启动。

【第 5 步】等待构建完成
  首次构建需要 5-10 分钟（两个容器会自动编译），期间两个服务状态显示构建中/健康检查中，
  最终都应显示"运行中"（health: healthy）。

【第 6 步】访问
  浏览器打开：  http://极空间IP:8080
  登录账号：admin，密码：第 4 步设置的 CHANGE_ME_ADMIN_PASSWORD

【数据与升级说明】
  - 所有数据（数据库 + 上传的病历图片）存在项目目录的 data/db、data/uploads 两个文件夹
  - 以后有新版本：拿到新版 zip → 解压覆盖（保留 data 文件夹）→ 在 Compose 里重新构建启动，
    数据自动保留
  - 备份 = 直接复制 data 文件夹；恢复 = 拷回 data 文件夹后重启服务

【常见问题】
  - 页面打不开 → 看 backend 容器日志，多半是密钥没填对或 OCR key 无效
  - 8080 端口被占用 → 把 ports 里 "8080:80" 改成 "其他端口:80"
  - 若 Compose 不支持 build（报错 build 相关）→ 告诉我，我给你换成预构建镜像方案
