# family-files 云服务器部署指南（火山引擎 ECS）

- **适用版本**：部署包 v12.6（账号模块）
- **服务器**：火山引擎 ECS · Ubuntu 22.04 · 共享型 2核2G（ecs.e-c1m1.large）
- **公网 IP**：115.190.114.202
- **访问地址**：http://115.190.114.202:18080
- **技术栈**：前端 React+Vite+Nginx 容器 + 后端 NestJS+SQLite 容器，Docker Compose 编排

> 与极空间的部署包完全一致，无需改造代码；云服务器是 x86 架构，比极空间（ARM）更顺利。

## 4. 解压并配置密钥

```bash
cd /root
unzip family_files_deploy.zip -d family_files
cd family_files

# 编辑密钥文件（三个必填项）
nano data/backend.env
```

`data/backend.env` 文件里修改这三个值：

| 变量 | 填什么 |
|---|---|
| `JWT_SECRET` | 随便一段长随机字符串，如 `Ff2026!xkQm7@zBv3#pLs9` |
| `OCR_API_KEY` | 你的 DeepSeek Key：`sk-47f19087b5144e5a86a5a810f8fdaada` |
| `SEED_ADMIN_PASSWORD` | **管理员登录密码**，设一个你记得住的强密码 |

保存退出：`Ctrl+O` 回车，然后 `Ctrl+X`。

> 说明：密钥只在首次启动时读取，之后会持久化进数据库；以后整体覆盖升级包时不会再丢密钥。

## 5. 配置安全组（★ 必须先做，否则公网访问不通）

1. 火山引擎控制台 → ECS → 实例 → 点实例名进入详情
2. 左侧「安全组」→ 找到实例绑定的安全组 → 点进去
3. 「入方向规则」→ **添加规则**：

| 字段 | 值 |
|---|---|
| 协议 | TCP |
| 端口 | **18080** |
| 来源 | 0.0.0.0/0 |

4. 保存。（22 端口通常默认已放行，用于 SSH 登录）

## 6. 启动服务

```bash
cd /root/family_files

# 首次构建+启动，约 3-5 分钟（拉基础镜像 + npm 安装依赖）
docker compose up -d --build

# 查看状态（两个容器都应为 running / healthy）
docker compose ps
```

查看启动日志（可选）：

```bash
docker compose logs -f backend
# 看到 "Nest application successfully started" 即后端就绪，Ctrl+C 退出
```

## 8. 日常运维

| 操作 | 命令 |
|---|---|
| 查看状态 | `docker compose ps` |
| 查看日志 | `docker compose logs -f` |
| 重启服务 | `docker compose restart` |
| 停止服务 | `docker compose down` |
| **备份数据** | `cd /root && tar czf backup-$(date +%F).tar.gz family_files/data/` |
| 恢复数据 | 解压备份覆盖 `family_files/data/` 后 `docker compose restart` |

**升级新版本**（保留数据）：

```bash
cd /root/family_files
# 1) 备份（习惯性动作，万一出事可回滚）
tar czf /root/backup-$(date +%F).tar.gz data/
# 2) 把新版代码覆盖进来（只覆盖 backend/ frontend/ docker-compose.yml 等代码文件，保留 data/）
# 3) 重新构建启动
docker compose up -d --build
```

## 9. 常见问题排查

| 现象 | 原因与处理 |
|---|---|
| 浏览器打不开 `http://IP:18080` | 90% 是**安全组没放行 18080**，回第 5 步检查 |
| `docker compose up` 拉镜像超时 | 部署包已内置国内镜像源（docker.m.daocloud.io）与 npm 镜像，正常不会；如偶发可重跑一次 |
| 登录提示密码错误 | `SEED_ADMIN_PASSWORD` 只在**首次创建 admin** 时生效；忘记密码可在用户管理页给 admin 重置（需用另一个管理员账号） |
| OCR 识别失败 | 检查 `data/backend.env` 里 `OCR_API_KEY` 是否填对，改完 `docker compose restart backend` |
| 服务起来了但很慢 | 2核2G 够用；图片上传多了可观察磁盘剩余（`df -h`），不足时在控制台扩容系统盘 |

## 10. 数据备份铁律

- SQLite 数据库 + 上传图片都在 `family_files/data/` 目录下，**备份这一个文件夹 = 备份全部数据**
- 建议每周手动执行一次第 8 节的备份命令，或把备份包下载到本地电脑/网盘
- 云服务器删了实例、换了机器，只要 backup 包还在，数据就还在
